# Fase 2.1A.12B.2 — registro de riscos e decisões

**Base de evidência:** código do snapshot `e5bf3147a7f9a5ee02e1a011ffcbf1fb7e0cc636`, com refs detalhadas em [auditoria](editorial-generations-phase-2-1a-12b2-audit.md). ## 2. Decisões que bloqueiam implementação/cutover

| Decisão | Donos necessários | Por que bloqueia |
|---|---|---|
| Semântica de concorrência do editor (409, rebase, fila) | Produto + backend | Determina se um comando reexecutado pode ser aplicado a revisão diferente sem alterar intenção |
| Política de aluno durante republish/restore | Produto educacional + backend/frontend | Define pin de sessão, tentativas abertas, progresso e retenção |
| Fonte canônica durante migração | Arquitetura + operações | Decide quando dados vivos deixam de ser fonte de verdade e como impedir escrita legacy |
| Granularidade de geração (track vs atividade) | Produto + backend | Impacta cache, atividade, versões e CAS |
| Tratamento de taxonomias/block type | Conteúdo + backend | Metadados globais podem mudar avaliação/render sem nova geração |
| Separação de roles/coleções privadas | Segurança + operações | DB grants de coleção não são projeção por documento/field |
| Retenção e exclusão | Produto + jurídico/privacidade, se aplicável | Necessário para progresso, submissions e tentativas históricas |
| Infra de MongoDB, backups e disponibilidade | Operações | PoC standalone prova protocolo naquele topology; não cobre capacidade, replica set nem restauração de backup |
| Janela de backfill e coortes de rollout | Produto + operação | Operação de dados e risco de cutover exigem autorização separada |

## 3. Leitura do risco nesta fase

O risco P1 não foi “corrigido” pela homologação da PoC. O snapshot atual contém uma preparação privada que bloqueia elegibilidade justamente porque não há revisão editorial comum. A decisão segura neste momento é manter esse bloqueio até todas as vias de escrita e leitura necessárias passarem pelos gates do roadmap. Não foram usados dados reais nem testes de produção para classificar a probabilidade; onde a intercalação exige execução, o registro a chama de inferência e aponta o teste futuro.
