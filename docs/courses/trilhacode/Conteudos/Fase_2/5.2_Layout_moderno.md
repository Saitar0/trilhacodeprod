# 5.2 — Layout moderno

## Objetivo
Compor layouts com Flexbox e CSS Grid, controlar alinhamento e distribuição e escolher a ferramenta conforme a estrutura do problema.

## Teoria

### Eixo principal do layout
Flexbox organiza itens em uma dimensão por vez: em linha ou coluna. O contêiner flex define o eixo principal e o eixo transversal. `justify-content` distribui espaço no eixo principal; `align-items` alinha itens no eixo transversal; `gap` cria espaçamento consistente. Itens podem crescer, encolher e quebrar linha conforme as regras definidas.

```css
.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}
```

Flexbox costuma funcionar bem para barras de navegação, grupos de botões ou alinhamento de itens relacionados em uma direção. Não é limitado a uma única linha; `flex-wrap` permite que itens ocupem novas linhas.

### Linhas e colunas com Grid
CSS Grid organiza conteúdo em duas dimensões, definindo linhas e colunas. O contêiner pode usar `grid-template-columns`, `grid-template-rows`, `gap` e posicionamento por linhas/áreas. Unidades flexíveis como `fr` distribuem espaço disponível; funções como `minmax()` ajudam a expressar limites.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;
}
```

Grid é útil quando linhas e colunas precisam se relacionar. Flexbox e Grid podem ser combinados: Grid para a estrutura da página e Flexbox dentro de cada componente, por exemplo.

### Alinhamento e distribuição
Identifique primeiro o contêiner e o espaço disponível. Alinhamento controla posição relativa; distribuição define como o espaço livre fica entre ou ao redor dos itens. Não confunda `align-content` (distribuição de linhas/colunas no contêiner) com `align-items` (alinhamento de itens). Nomes e efeitos dependem do modo de layout e dos eixos.

### Itens, faixas e conteúdo mínimo
Grid cria faixas explícitas quando você as declara; conteúdo que excede essa definição pode criar faixas implícitas. O tamanho mínimo automático de itens pode impedir que uma coluna encolha como esperado, sobretudo quando há conteúdo longo. `minmax(0, 1fr)` permite que a faixa flexível encolha até zero; `min-width: 0` pode ser necessário no próprio item para que seu conteúdo não force o contêiner a transbordar. Antes de aplicar essas regras, confirme qual caixa está causando o overflow e trate palavras ou mídias que não podem quebrar ou encolher.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
}

.card { min-width: 0; }
```

## Resumo
- Flexbox organiza principalmente ao longo de um eixo; Grid estrutura linhas e colunas em duas dimensões.
- `justify-content` e `align-items` atuam em eixos diferentes, definidos pelo modo de layout.
- `gap` oferece espaçamento entre itens sem margens acumuladas.
- `flex-wrap` permite quebra de linha.
- Grid usa tracks, `fr`, `minmax()` e áreas para compor uma grade.
- Conteúdo mínimo pode impedir itens ou faixas de encolher; investigue o elemento que transborda antes de ajustar `min-width` ou `minmax()`.
- Os dois modelos se complementam; escolha pelo relacionamento entre os elementos.

## Verificação — quiz
1. Para uma barra de navegação com itens alinhados em uma direção, qual ferramenta costuma ser adequada? **A)** Flexbox. **B)** `position: absolute` em cada item. **C)** Tabela HTML. **D)** Apenas `float`. **Resposta: A.** Flexbox organiza itens relacionados ao longo de um eixo e permite controlar espaçamento e quebra; coordenadas absolutas não acompanham bem o fluxo de conteúdo.
2. Qual cenário combina mais diretamente com Grid? **A)** Layout que precisa relacionar linhas e colunas. **B)** Um único link. **C)** Alterar cor do texto. **D)** Criar requisição HTTP. **Resposta: A.** Grid define faixas nas duas dimensões; as outras opções não descrevem uma necessidade de estrutura bidimensional.
3. Em um contêiner flex em `row`, o eixo principal é: **A)** vertical. **B)** horizontal, no sentido da linha (respeitando direção de escrita). **C)** sempre diagonal. **D)** inexistente. **Resposta: B.** `row` acompanha a direção inline do contexto, que pode ser invertida pela direção de escrita; não é sempre da esquerda para a direita.
4. É obrigatório escolher entre Flexbox e Grid para a página inteira? **A)** Sim. **B)** Não; podem ser combinados em níveis diferentes. **C)** Sim, mas apenas Grid pode ser usado em componentes. **D)** Nenhum pode ser combinado. **Resposta: B.** Cada contêiner pode usar o modelo que melhor expressa sua relação entre itens. É comum combinar Grid na página e Flexbox dentro de componentes.
5. Uma grade de duas colunas transborda quando um cartão contém uma sequência longa sem espaços. Qual investigação/correção é mais apropriada? **A)** Aplicar `position: absolute` a todos os cartões. **B)** Remover o conteúdo longo sem investigar. **C)** Inspecionar a faixa e o item; testar `minmax(0, 1fr)` e `min-width: 0`, além de decidir como o texto pode quebrar. **D)** Trocar Grid por tabela HTML automaticamente. **Resposta: C.** O tamanho mínimo automático de uma faixa/item pode resistir ao encolhimento. A correção depende de identificar a caixa e também do comportamento desejado para o conteúdo; posicionamento absoluto ou troca automática de tecnologia não explicam a causa.

## Práticas

### 1. Guiada — diagnostique e corrija a composição
Considere este HTML e CSS. O cartão longo empurra a grade para fora do contêiner e os botões da barra não mantêm espaçamento.

```html
<nav class="toolbar"><a href="/inicio">Início</a><a href="/ajuda">Ajuda</a></nav>
<main class="cards">
  <article class="card"><h2>Guia</h2><p>Introdução</p></article>
  <article class="card"><h2> identificador-extremamente-longo-sem-quebras </h2><p>Detalhes</p></article>
</main>
```

```css
.toolbar { display: block; justify-content: space-between; }
.cards { display: grid; grid-template-columns: repeat(2, 1fr); gap: 1rem; }
```

**Tarefa:** explique por que `justify-content` não distribui os links na barra, identifique o risco de overflow na grade e proponha uma correção sem posicionar cada item manualmente.

**Dicas graduais:** (1) confira o `display` do contêiner que deveria distribuir os links; (2) confirme que Grid cria duas faixas; (3) inspecione a largura mínima do item e decida como a sequência longa deve quebrar.

**Solução comentada:** use `display: flex; align-items: center; justify-content: space-between; gap: 1rem` na barra. Na grade, teste `repeat(2, minmax(0, 1fr))` e `min-width: 0` no cartão se o item continuar forçando a faixa; escolha uma regra de quebra de texto apropriada ao projeto, como `overflow-wrap: anywhere`, se quebrar identificadores for aceitável. Confirme no navegador com largura reduzida. A causa deve ser observada: não aplique as três declarações sem verificar qual resolve o problema.

**Erros comuns:** esperar que `justify-content` funcione sem um modo de layout que distribua itens; acreditar que `1fr` sempre ignora o tamanho mínimo do conteúdo; ocultar overflow sem avaliar se isso corta informação.

### 2. Independente — mapeie requisitos para contêineres
Projete, para a página já criada no curso, uma área principal com título, uma barra de ações e uma coleção de quatro cartões. Antes de escrever o CSS, faça um mapa `Região | Relação entre itens | Modelo escolhido | Evidência/razão`.

Implemente pelo menos um contêiner com Flexbox e um com Grid. Defina o que deve acontecer quando a barra não couber em uma linha e quando os cartões perderem espaço. Registre quais propriedades controlam alinhamento no eixo principal e transversal da barra. Não é necessário copiar uma referência visual nesta etapa.

**Dicas graduais:** (1) pergunte se a relação dominante é uma sequência ou linhas e colunas; (2) desenhe os dois eixos antes de escolher propriedades de alinhamento; (3) teste com texto de comprimentos diferentes e janela estreita.

**Critérios de aceite:** mapa coerente com a estrutura; uso justificado dos dois modelos; comportamento de falta de espaço descrito e observado; nenhuma região principal depende de coordenadas absolutas. Resposta varia conforme o HTML, então a justificativa e a evidência valem mais que uma combinação específica de propriedades.

### 3. Transferência — reproduza e revise um layout de referência
Escolha uma página simples com cabeçalho, navegação, área principal e cartões. Construa a estrutura com o HTML existente e reproduza a composição usando Grid para relações bidimensionais e Flexbox para grupos unidimensionais. Registre por que cada contêiner usa aquele modo e como os itens se comportam quando falta espaço.

**Entregue:** referência identificada, mapa de contêineres, CSS relevante, comparação visual em largura ampla e estreita e uma nota sobre qualquer diferença que você decidiu manter.

**Aceite:** relações visuais são reproduzidas; alinhamento e distribuição são explicados pelos eixos; existe ao menos um uso justificado de cada ferramenta; componentes não dependem de coordenadas absolutas para o fluxo principal; nenhum conteúdo é cortado sem decisão explícita.

**Rubrica (0–2 por critério):** (1) escolha Grid/Flexbox corresponde às relações; (2) eixos e alinhamento explicados; (3) comportamento de espaço insuficiente demonstrado; (4) revisão visual e justificativa de desvios. `0` = ausente/incorreto, `1` = parcial, `2` = claro e demonstrado. Pronto com pelo menos 6/8 e sem overflow ou conteúdo cortado sem tratamento.

## Critério de conclusão
Escolher entre Flexbox e Grid para cada parte do layout e justificar a escolha com base nos eixos, linhas/colunas e comportamento do conteúdo.
