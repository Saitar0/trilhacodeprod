# 4.1 — Estrutura de documento

## Objetivo
Escrever um documento HTML completo e válido com metadados, títulos, texto, listas, links, imagens, tabelas e formulários, escolhendo elementos adequados ao conteúdo.

## Teoria

### HTML descreve estrutura e significado
HTML (HyperText Markup Language) é uma linguagem de marcação que organiza o conteúdo de uma página. Um elemento costuma ser escrito com uma tag inicial, conteúdo e tag final; elementos vazios, como `img` e `meta`, não envolvem conteúdo da mesma forma. Atributos acrescentam informações ao elemento, como `href` em links e `src` em imagens.

Um documento começa com `<!doctype html>`, seguido de `<html lang="pt-BR">`. O `<head>` contém metadados, título da aba e ligações a recursos; o `<body>` contém conteúdo apresentado na página. Use títulos em ordem lógica, parágrafos para texto, listas para conjuntos relacionados e links para destinos navegáveis.

```html
<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Portfólio de Ana</title>
  </head>
  <body>
    <h1>Ana Silva</h1>
    <p>Desenvolvedora em formação.</p>
    <a href="https://example.com">Meu perfil</a>
  </body>
</html>
```

### Links, imagens e tabelas
Um link (`a`) precisa de um destino e de um texto que deixe claro o que acontecerá. Imagens (`img`) usam `src`; o atributo `alt` fornece alternativa textual conforme a finalidade da imagem. Tabelas (`table`) organizam dados tabulares, não devem ser usadas apenas para posicionar elementos. Use cabeçalhos de coluna/linha (`th`) e associe-os de forma clara aos dados.

### Formulários
`form` agrupa controles que coletam informações. Cada controle deve ter um nome identificável, geralmente por um `<label>` associado ao `id` do controle. `input` oferece tipos diferentes; `textarea` permite texto maior; `select` oferece opções; `button` executa uma ação. Atributos como `action` e `method` descrevem para onde e como o formulário envia os dados, quando há um destino configurado.

Não use placeholder como substituto do rótulo: ele desaparece quando a pessoa começa a digitar. Controles nativos oferecem comportamento e semântica que seriam difíceis de recriar manualmente.

### Aninhar e validar o documento
Elementos devem ser organizados de acordo com sua estrutura e fechados de forma coerente. Um parágrafo pode conter texto e links, mas não deve envolver uma lista ou uma tabela. Feche o elemento dentro do qual começou antes de fechar o elemento externo. A identação ajuda a enxergar essa hierarquia, embora não altere por si só a estrutura interpretada pelo navegador.

Um validador HTML aponta problemas de sintaxe e conformidade que podem passar despercebidos. Corrija erros, examine avisos e teste o resultado no navegador. Validação não garante que o conteúdo esteja claro, que links e imagens carreguem ou que a página seja acessível; essas verificações exigem revisão própria.

## Resumo
- HTML organiza conteúdo e dá estrutura; tags e atributos formam elementos.
- `head` guarda metadados; `body`, conteúdo da página.
- Use títulos, parágrafos, listas e links de acordo com o significado.
- Imagens precisam de `alt` apropriado; tabelas são para dados tabulares.
- Formulários agrupam controles; associe cada campo ao seu `label`.
- `input`, `textarea`, `select` e `button` têm papéis diferentes.
- Aninhamento coerente facilita a leitura; validador e navegador ajudam a encontrar problemas diferentes.

## Verificação — quiz
1. Onde fica o título exibido na aba do navegador? **A)** `head` em `title`. **B)** `footer`. **C)** `label`. **D)** `table`. **Resposta: A.**
2. Para que serve `alt` em uma imagem? **A)** Alterar a cor. **B)** Fornecer uma alternativa textual apropriada à imagem. **C)** Carregar a imagem. **D)** Definir o link. **Resposta: B.**
3. Quando uma tabela é apropriada? **A)** Para organizar dados com relação entre linhas e colunas. **B)** Para criar qualquer layout de página. **C)** Para aumentar espaçamento. **D)** Para substituir listas sempre. **Resposta: A.**
4. Qual prática torna um campo de formulário identificável? **A)** Só placeholder. **B)** Label associado ao controle. **C)** Cor diferente. **D)** Nome de arquivo. **Resposta: B.**
5. Para associar explicitamente um `label` a um controle, qual relação precisa existir? **A)** `for` do label igual ao `name` do controle. **B)** `for` do label igual ao `id` do controle. **C)** `title` do label igual ao `src`. **D)** O label precisa vir depois do botão. **Resposta: B.** O `for` identifica o `id` do controle correspondente.

## Prática — três níveis

Faça as atividades nesta ordem. Use somente informações fictícias; não publique dados pessoais. A atividade final é uma página completa e deve ser validada.

### 1. Guiada — repare uma página incompleta

O arquivo abaixo representa uma página de guia de estudos. Identifique pelo menos seis melhorias relacionadas a idioma e metadados, fechamento/aninhamento, link, imagem, tabela e formulário. Reescreva o trecho para que atenda ao briefing: idioma português do Brasil; título da aba “Guia de estudos”; lista de três tópicos; link para o perfil do grupo com texto descritivo; imagem informativa com alternativa textual; tabela com cabeçalhos de fase e status; campo de e-mail associado a um rótulo. O formulário é demonstrativo e não deve enviar dados.

```html
<!doctype html>
<html>
<head>
  <title>Guia de estudos</title>
<body>
  <h1>Guia de estudos
  <p>Materiais para a próxima etapa
  <ul><li>HTML<li>CSS<li>JavaScript</ul>
  <a href="https://example.com">Clique aqui</a>
  <img src="mapa.png">
  <table>
    <tr><td>Fase</td><td>Status</td></tr>
    <tr><td>HTML</td><td>Em andamento</td></tr>
  </table>
  <form>
    <input id="email" type="email" placeholder="E-mail">
    <button>Enviar</button>
  </form>
</body>
</html>
```

**Gabarito comentado:** uma versão possível é:

```html
<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Guia de estudos</title>
  </head>
  <body>
    <h1>Guia de estudos</h1>
    <p>Materiais para a próxima etapa.</p>
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
    <a href="https://example.com/perfil">Perfil do grupo de estudos</a>
    <img src="mapa.png" alt="Mapa com as etapas do guia de estudos">
    <table>
      <tr><th>Fase</th><th>Status</th></tr>
      <tr><td>HTML</td><td>Em andamento</td></tr>
    </table>
    <form>
      <label for="email">E-mail para contato demonstrativo</label>
      <input id="email" name="email" type="email">
      <button type="button">Enviar</button>
    </form>
  </body>
</html>
```

O destino e o texto do link podem variar se continuarem claros. O texto alternativo deve descrever a informação relevante da imagem. `button type="button"` evita enviar o formulário neste exemplo sem backend. Um validador pode apontar problemas de marcação, mas não confirma se o arquivo de imagem existe nem se o destino do link é o correto.

### 2. Independente — produza uma página de recursos

Crie `recursos.html` para um grupo de estudos fictício. A página deve explicar o propósito em um título principal e um parágrafo; listar três recursos; incluir um link externo com texto que descreva o destino; apresentar uma imagem informativa com texto alternativo; organizar uma pequena tabela de encontros com cabeçalhos; e conter um formulário demonstrativo com um campo de e-mail associado a um `label`. Declare o idioma, defina metadados básicos e feche e aninhe os elementos corretamente.

**Dicas progressivas**

- Escreva primeiro o esqueleto completo do documento (`doctype`, `html`, `head`, `body`) e depois encaixe cada conteúdo no lugar adequado.
- Antes de validar, confira se `for` e `id` do campo correspondem, se cada dado de tabela está sob o cabeçalho certo e se o formulário não envia informação real.

**Critérios de autocorreção (0–2 pontos cada; total 10)**

- Documento completo, idioma e metadados básicos corretos.
- Título, parágrafo e lista representam o briefing.
- Link tem destino e texto descritivo; imagem tem alternativa adequada.
- Tabela organiza dados tabulares e tem cabeçalhos identificáveis.
- Campo tem label associado; formulário não envia dados reais; validador não aponta erros de marcação.

Considere a atividade concluída com pelo menos 8 pontos. Revise cada erro do validador, mas avalie também manualmente link, imagem e formulário.

### 3. Transferência — página de currículo

Crie do zero uma página HTML de currículo fictício com título e metadados corretos, nome e apresentação, listas de competências e experiências, link para um perfil, imagem com alternativa apropriada e tabela pequena com dados realmente tabulares. Inclua um formulário de contato demonstrativo com labels; como a página não terá backend, use somente dados de exemplo e mantenha o botão como não-submissor. Não use framework. Valide o documento completo com um validador HTML, corrija erros de marcação e revise os avisos que se aplicarem.

**Aceite:** documento começa com doctype e tem `html`, `head` e `body`; idioma declarado; hierarquia de títulos coerente; links têm texto descritivo; imagem tem alternativa; tabela usa cabeçalhos; campos têm labels associados; formulário não envia dados; HTML está bem aninhado e não apresenta erros de marcação no validador. A pessoa também revisa no navegador se links e imagem funcionam.

## Critério de conclusão
Escrever um documento HTML válido sem copiar um modelo pronto e justificar por que escolheu cada elemento principal.
