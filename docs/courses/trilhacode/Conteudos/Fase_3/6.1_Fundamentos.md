# 6.1 — Fundamentos de JavaScript

## Objetivo
Usar variáveis, tipos, operadores, condicionais e laços para transformar entradas em resultados previsíveis.

## Teoria

### Valores e tipos
Um programa manipula **valores**. JavaScript é dinamicamente tipada: o valor tem um tipo, mas uma variável pode receber valores de tipos diferentes. Tipos primitivos incluem `number`, `string`, `boolean`, `undefined`, `null`, `bigint` e `symbol`; `object` é outro tipo, e arrays e funções são objetos em sentido técnico. Nesta unidade, concentre-se em `number`, `string`, `boolean`, `undefined`, `null` e arrays.

`typeof` ajuda a inspecionar alguns valores, mas tem particularidades: `typeof null` retorna `"object"` por uma compatibilidade histórica. Portanto, para testar `null`, compare explicitamente com `=== null`. Uma variável declarada sem valor inicial com `let` recebe `undefined`; isso não é igual a `null`, que representa ausência intencional de valor em muitos contextos.

### Variáveis e reatribuição
Use `const` por padrão quando a associação não será reatribuída; use `let` quando o valor associado precisar mudar, como um acumulador. `const` não torna um objeto imutável: suas propriedades ainda podem mudar. Escolha nomes que expliquem o papel do valor e mantenha variáveis próximas ao trecho que as usa.

```js
const nome = "Lia";
let tentativas = 0;
tentativas = tentativas + 1;
```

### Operadores e conversão
Operadores calculam ou comparam valores. Use `===` e `!==` para comparar sem a conversão implícita comum de `==` e `!=`. O operador `+` soma números, mas concatena quando um operando é string: `"8" + 2` resulta em `"82"`. Por isso, identifique o tipo das entradas e converta ou rejeite valores explicitamente antes de calcular. Comparações (`>`, `<=`) e operadores lógicos (`&&`, `||`, `!`) compõem condições.

### Decisões com condicionais
`if/else` escolhe um caminho conforme uma expressão que pode ser avaliada como verdadeira ou falsa. Use comparações explícitas para tornar a regra legível e considere os limites: se aprovação ocorre com nota 7, `media >= 7` inclui exatamente 7, enquanto `media > 7` não inclui. Mais de duas faixas podem usar `else if`, cuidando da ordem das condições.

### Repetições e encerramento
Laços repetem operações. `for` é útil quando o controle de início, condição e atualização fica explícito; `while` continua enquanto sua condição for verdadeira; `for...of` percorre valores iteráveis, como elementos de um array, sem expor o índice. Garanta que o laço terá uma condição de parada. Para um array vazio, `for...of` executa zero vezes; qualquer cálculo posterior deve tratar o caso antes de dividir pelo tamanho do array.

```js
const notas = [8, 6, 9];
let total = 0;

for (const nota of notas) {
  total += nota;
}

const media = notas.length === 0 ? 0 : total / notas.length;
if (media >= 7) {
  console.log(`Aprovada: ${media}`);
} else {
  console.log(`Revisar: ${media}`);
}
```

## Resumo
- Variáveis guardam referências a valores; tipos pertencem aos valores em JavaScript.
- Prefira `const`; use `let` quando a associação precisar mudar.
- `===` reduz surpresas de coerção; converta entradas quando necessário.
- Condicionais escolhem um caminho; laços repetem até uma condição encerrar.
- `for...of` percorre valores iteráveis; teste arrays vazios e condições de parada.
- Confira o tipo dos dados antes de somar; `+` também pode concatenar strings.

## Verificação — quiz
1. O que `const` garante? **A)** Que o objeto nunca muda. **B)** Que a variável não pode ser reatribuída. **C)** Que o valor é sempre número. **D)** Que o valor é global. **Resposta: B.** Propriedades de um objeto ainda podem ser alteradas, então `const` não congela o conteúdo. Tipo e escopo também não são definidos por essa palavra.
2. Por que `===` costuma ser preferível a `==`? **A)** Compara sem a coerção implícita comum do `==`. **B)** Faz arredondamento. **C)** Compara apenas objetos. **D)** Evita toda validação. **Resposta: A.** A igualdade estrita torna explícita a diferença de tipo; ela não arredonda, não é limitada a objetos e não substitui validação de entradas.
3. O que pode causar um loop infinito? **A)** A condição de continuação nunca se tornar falsa. **B)** Usar `for...of`. **C)** Declarar `const`. **D)** Um array vazio em qualquer caso. **Resposta: A.** Se a condição continuar verdadeira e nada a tornar falsa, o laço não termina. `for...of` sobre um array vazio executa zero vezes.
4. O que `typeof null` retorna em JavaScript? **A)** `"null"`. **B)** `"object"`. **C)** `"undefined"`. **D)** `"boolean"`. **Resposta: B.** É uma particularidade histórica; teste `null` com `valor === null` em vez de confiar em `typeof`.
5. Qual é o resultado de `"8" + 2`? **A)** `10` do tipo number. **B)** `"82"` do tipo string. **C)** `"10"` do tipo string. **D)** Um erro de sintaxe. **Resposta: B.** Com `+`, se um operando é string, ocorre concatenação. Para somar numericamente, converta e valide o valor primeiro; o operador não faz essa validação por conta própria.

## Práticas

### 1. Guiada — depure um acumulador
Preveja o resultado antes de alterar o código. Depois localize o erro e corrija-o.

```js
const valores = [8, 6, 9];
let total = 0;

for (let indice = 0; indice <= valores.length; indice++) {
  total += valores[indice];
}

const media = total / valores.length;
console.log(total, media);
```

**Tarefa:** explique por que o resultado não é o total e a média esperados; corrija o limite do laço; depois substitua a inicialização por `const valores = []`, descreva o resultado e acrescente o tratamento necessário.

**Dicas graduais:** (1) liste os índices existentes no array; (2) observe o valor acessado quando `indice` é igual a `valores.length`; (3) antes de dividir, verifique se há elementos.

**Solução comentada:** os índices válidos são `0`, `1` e `2`. Com `<=`, o laço também acessa `valores[3]`, que é `undefined`; somar esse valor ao total produz `NaN`. Troque `<=` por `<`. Para o array vazio, não há valores para somar e a média não deve ser calculada dividindo por zero; trate a lista antes e informe “sem valores” ou adote uma regra explícita, em vez de inventar média zero sem decisão.

**Erro comum:** corrigir o limite do laço e esquecer o caso vazio; ou assumir que `undefined` é ignorado na soma.

### 2. Independente — conte resultados acima de um limite
Considere `const temperaturas = [18, 23, 21, 15, 27];`. Escreva um algoritmo que percorra os valores e conte quantos são maiores ou iguais a `20`. Antes de executar, faça uma tabela com `valor | condição | contador após a etapa`.

Depois, explique o resultado para a lista original e para `[]`. Não use método de array nesta atividade: o objetivo é praticar variável, comparação e repetição. Declare como `const` as associações que não serão reatribuídas e use `let` para o contador.

**Dicas graduais:** (1) o contador começa em zero; (2) a cada valor, teste `temperatura >= 20`; (3) só incremente quando a condição for verdadeira. Um array vazio deve resultar em zero ocorrências.

**Critérios de aceite:** tabela de rastreamento correta; código conta 3 valores na lista fornecida e 0 na lista vazia; limite `>=` explicado; laço termina. O gabarito é o rastreamento e esses resultados, não uma forma única de escrever o algoritmo.

### 3. Transferência — console de notas
Escreva um programa que recebe um array de notas numéricas, calcula total e média, informa aprovação segundo a regra definida (`média >= 7`) e trata a lista vazia. Conte também quantas notas individuais alcançam a média da turma. As entradas são um array já construído em JavaScript; leitura de formulário e conversão de texto serão estudadas depois.

**Entregue:** código, resultado para `[8, 6, 9]`, resultado para `[]` e explicação de cada variável, condição e laço. Defina explicitamente o comportamento para lista vazia. Se decidir rejeitar valores não numéricos, faça essa verificação antes de calcular e mostre a mensagem resultante.

**Dicas graduais:** (1) some as notas com um acumulador; (2) trate o array vazio antes da divisão; (3) calcule a média antes de iniciar a contagem de notas maiores ou iguais a ela.

**Aceite:** para `[8, 6, 9]`, total `23`, média `23 / 3` (aproximadamente `7,67`), aprovação e 2 notas iguais ou acima da média; lista vazia tratada; laço termina e explicação permite acompanhar os valores.

**Rubrica (0–2 por critério):** (1) tipos e variáveis escolhidos com coerência; (2) acumulador e laço corretos; (3) limites e caso vazio tratados; (4) condição de aprovação e rastreamento explicados. `0` = ausente/incorreto, `1` = parcial, `2` = claro e verificável. Pronto com pelo menos 6/8 e sem erro no caso vazio ou no limite do laço.

**Aceite:** trata lista vazia; usa comparação apropriada; entradas não numéricas são identificadas ou rejeitadas; laço termina; resultado é reproduzível.
