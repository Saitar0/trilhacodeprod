## Objetivo
Reconhecer os modelos de componentes, reatividade e organização de Vue 3 e Angular; identificar Vue 2 como tecnologia em fim de vida; e transferir conceitos de React sem presumir que suas APIs sejam iguais.

## Microtópico 1 — Compare como os frameworks descrevem a interface
Vue 3 usa componentes, templates e um sistema de reatividade. Em componentes de arquivo único, template, lógica e estilo podem ficar juntos. Há duas formas oficiais de organizar a lógica: **Options API**, que agrupa opções como dados e métodos, e **Composition API**, que usa funções como `ref()` e hooks de ciclo de vida. `<script setup>` é uma forma comum de escrever componentes com Composition API. Options API continua suportada; Composition API facilita agrupar lógica por funcionalidade quando um componente cresce.

Angular organiza aplicações com componentes e templates em TypeScript e inclui mecanismos integrados para serviços, injeção de dependências, roteamento e ferramentas de desenvolvimento. Componentes standalone importam diretamente as dependências do template e são recomendados pela equipe Angular para código novo; `NgModule` continua importante para compreender projetos existentes.

Os dois frameworks resolvem desafios parecidos — composição, estado, eventos, formulários, acessibilidade e chamadas a serviços — com convenções diferentes. O modelo React ajuda a entender componentização e fluxo de dados, mas não ensina automaticamente a sintaxe de templates do Vue ou o sistema de DI do Angular.

## Microtópico 2 — Reconheça versões, padrões atuais e legado
Em Vue, `ref()` e `reactive()` criam estado reativo na Composition API; templates acompanham mudanças e atualizam a interface. Em Angular atual, componentes e templates se relacionam com estado e serviços por mecanismos próprios do framework, incluindo injeção de dependências. Ao ler um código, identifique o padrão e a versão em vez de traduzir mentalmente cada API para React.

Vue 2 chegou ao fim de vida em **31 de dezembro de 2023**. Ele permanece em aplicações existentes e pode aparecer em manutenção ou migração, mas não deve ser apresentado como a base padrão para projetos novos. Vue 3 é a versão atual. Angular moderno recomenda standalone para código novo, embora bases anteriores usem `NgModule`. Consulte documentação da versão concreta antes de aplicar uma receita a um repositório legado.

Compare ecossistemas pelo problema: convenções da equipe, dependências, manutenção, acessibilidade e requisitos do produto. Este panorama serve para reconhecer modelos e ler documentação; não pretende eleger um framework universalmente superior nem substituir um curso de implementação completo.

## Resumo
- Vue 3 oferece templates, reatividade e Options API ou Composition API.
- Angular integra componentes e templates com serviços, injeção de dependências e ferramentas; standalone é recomendado para código novo.
- Conceitos de React são transferíveis, mas sintaxes, APIs e convenções precisam ser aprendidas no framework escolhido.
- Vue 2 chegou ao fim de vida em 2023 e deve ser reconhecido como legado; código novo deve partir de Vue 3.

## Flashcards
- **Vue template é JSX do React?** Não. Vue usa sua própria sintaxe de template, embora ambos descrevam uma interface declarativa.
- **Como Angular compartilha serviços entre partes da aplicação?** Por injeção de dependências, que fornece serviços ou valores aos componentes e outras classes.
- **Vue 2 é o padrão indicado para iniciar um projeto novo?** Não. Vue 2 chegou ao fim de vida; use Vue 3 para código novo e reconheça Vue 2 ao manter legado.

## Atividades

### Atividade 1 — Compare um pequeno componente
Partindo de um contador com botão em React, descreva como ele seria organizado em Vue 3 com template e `ref()`, e em Angular com componente, template e estado. Não precisa construir três aplicações: destaque onde ficam estado, evento e marcação. **Entrega:** comparação curta lado a lado.

**Critério:** diferencia sintaxe e modelo de reatividade sem confundir todos com JSX ou APIs React.

### Atividade 2 — Reconheça padrões em código e versões
Leia um trecho Vue com Options API ou Vue 2 e um trecho Angular com `NgModule`. Identifique sinais de framework e versão/padrão, indique como a documentação atual orienta um projeto novo e liste o que precisa ser verificado antes de migrar o trecho. **Entrega:** anotações breves de leitura e uma recomendação contextual.

**Critério:** distingue Vue 2 de Vue 3, reconhece Options API como ainda suportada e identifica `NgModule` como padrão encontrado em bases existentes.

## Critério de conclusão
Compare componentes, reatividade e organização de Vue 3 e Angular em termos concretos; reconheça Vue 2 como legado em fim de vida; e explique por que conhecimento de React transfere conceitos, mas não APIs.
