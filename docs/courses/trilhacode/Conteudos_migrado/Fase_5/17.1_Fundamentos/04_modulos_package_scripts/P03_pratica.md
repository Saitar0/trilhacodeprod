### Atividade 3 — Declarar módulos e scripts do projeto
Crie ou revise um package.json mínimo para um pequeno programa Node. Escolha ESM ou CommonJS, declare o formato explicitamente e configure um script para executar o programa. Escreva duas instruções de execução no README e explique como uma extensão .mjs ou .cjs se comporta caso o projeto precise misturar formatos.

**Dica:** o campo type afeta os arquivos .js dentro de seu pacote; não misture sintaxe ESM e CommonJS no mesmo arquivo.
