**Solução de referência:** declarar type como module e usar import/export consistentemente, ou declarar commonjs e usar require/module.exports; registrar o comando em scripts e executá-lo via npm. Para misturar formatos, usar extensões explícitas e seguir a interoperabilidade documentada para a versão de Node em uso.
