## Referências
- [OWASP — Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) — negar por padrão e verificar toda requisição; consultado em 14/10/2026.
- [OWASP API Security — API1:2023 Broken Object Level Authorization](https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/) e [API3:2023 Broken Object Property Level Authorization](https://api-security.owasp.org/editions/2023/en/0xa3-broken-object-property-level-authorization/) — autorização de objeto e propriedade; consultados em 14/10/2026.
- [OWASP API Security — API4:2023 Unrestricted Resource Consumption](https://api-security.owasp.org/editions/2023/en/0xa4-unrestricted-resource-consumption/) e [NestJS — Rate Limiting](https://docs.nestjs.com/security/rate-limiting) — limites de consumo, rate limit e configuração atrás de proxy; consultados em 14/10/2026.
- [Lei nº 13.709/2018 — LGPD, texto compilado](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709compilado.htm) — princípios de tratamento e medidas de segurança; consultado em 14/10/2026.
- [ANPD — Direitos dos titulares](https://www.gov.br/anpd/pt-br/assuntos/titular-de-dados/direito-dos-titulares) — referência institucional para direitos e contexto do tratamento; consultado em 14/10/2026.
