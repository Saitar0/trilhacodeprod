## Práticas

### Atividade 1 — Desenhar o contrato de um recurso
Para um recurso tarefas, proponha rotas para listar, consultar por ID, criar, substituir, alterar parcialmente e remover. Para cada rota, indique método, caminho, entrada esperada, status de sucesso e dois erros plausíveis. Inclua uma rota de listagem com filtro por estado e explique por que o filtro é query parameter. Marque quais operações são seguras ou idempotentes conforme o contrato.

**Dica:** comece pelo recurso e depois associe a intenção do cliente ao método. Para criação, deixe claro quem escolhe o identificador; para remoção, decida o comportamento de uma repetição.
