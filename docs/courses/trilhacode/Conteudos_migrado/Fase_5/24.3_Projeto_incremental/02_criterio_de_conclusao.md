## Critério de conclusão
Os quatro marcos são entregues; API autenticada persiste no PostgreSQL após migrations; testes de serviço e rota demonstram regra, validação, persistência e negação de acesso; cache tem política testada ou justificativa para ausência; o projeto pode ser iniciado e verificado com as instruções e o Compose documentados.
