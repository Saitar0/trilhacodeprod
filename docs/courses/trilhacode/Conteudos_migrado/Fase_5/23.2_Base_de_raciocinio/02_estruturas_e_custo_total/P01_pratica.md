## Atividades práticas

### Atividade 1 — Faça a conta de buscas repetidas

**Desafio:** compare buscar por ID em uma lista com construir um Map uma vez e consultar nele.

**Passos:**
1. Defina n como número de itens e q como número de consultas.
2. Descreva o pior cenário de uma busca linear e o trabalho de q buscas.
3. Descreva separadamente o custo de construir o índice, consultá-lo q vezes e armazená-lo.
4. Compare três casos: q = 1, q proporcional a n e q muito maior que n.
5. Escreva a hipótese sobre o comportamento de consulta no Map da linguagem utilizada.

**Dica:** não esqueça de incluir a preparação do Map na comparação.
