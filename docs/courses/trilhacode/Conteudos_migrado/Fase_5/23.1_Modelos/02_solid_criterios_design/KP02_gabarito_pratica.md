**Solução de referência:** manter a regra de reserva no caso de uso ou serviço de aplicação; deixar o controller lidar com HTTP; delegar persistência ao adapter de uma porta usada pelo caso de uso; enviar e-mail por um contrato apenas se essa integração precisar ser substituída, isolada ou testada à parte. Não extrair cada método para uma classe sem motivo observável.
