**Solução de referência:** controller adapta o pedido para o caso de uso; o caso de uso verifica conflito por meio de uma porta de consulta e solicita persistência por uma porta apropriada; o adapter PostgreSQL implementa essas operações. Não é necessário criar uma porta para o controller, relógio ou todo serviço se isso não resolver um risco concreto.
