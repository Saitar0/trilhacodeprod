## Critério de conclusão
Outra pessoa consegue executar o projeto localmente, repetir o cenário central do tipo, verificar fila/retry/DLQ/idempotência e compreender as decisões no ADR. A cobertura é atualizada apenas para tipo pendente que cumpriu seus critérios; aprofundamento livre não concede crédito adicional.
