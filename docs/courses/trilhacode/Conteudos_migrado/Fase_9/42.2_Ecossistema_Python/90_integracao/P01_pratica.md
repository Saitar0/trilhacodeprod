### Atividade 1 — Escolha a ferramenta proporcional
**Contexto:** considere três solicitações: (A) gerar relatório grande depois de responder “pedido recebido”; (B) validar rapidamente uma função que calcula desconto; (C) permitir que toda a equipe instale as mesmas versões de dependências de um serviço Python.

**Instruções:** associe cada situação a Celery, pytest ou Poetry; descreva o papel, uma alternativa aproximada em Node e uma responsabilidade que a ferramenta não resolve sozinha. Para A, explique qual estado o usuário acompanha; para B, diga quando um teste de integração seria necessário; para C, diferencie `pyproject.toml` e lockfile.

**Entrega:** tabela com uma linha por situação: problema, ferramenta, por que se aplica, limite e evidência que comprovaria o resultado.

**Dica gradual:** pergunte se o problema é executar trabalho depois, verificar comportamento ou reproduzir dependências.
