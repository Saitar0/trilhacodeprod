## Objetivo
Reconhecer o caminho de uma requisição numa API Django REST Framework (DRF), relacionar seus componentes aos conceitos de Node já estudados e identificar onde ficam validação, persistência e autorização. Construção completa é opcional e só se aplica se Django for a stack escolhida.
