- **Slim inclui ORM obrigatório?** Não. A aplicação escolhe persistência e integra bibliotecas.
- **O que PSR-7 representa em Slim?** Interfaces comuns para mensagens HTTP de request e response; as rotas Slim 4 devem devolver uma Response compatível.
