- **ECS é Kubernetes?** Não; é orquestrador AWS com API e conceitos próprios.
- **EKS elimina gestão de cluster?** Gerencia control plane; outras responsabilidades variam por modo.
- **Fargate elimina observabilidade?** Não; aplicação e serviço ainda precisam ser monitorados.
