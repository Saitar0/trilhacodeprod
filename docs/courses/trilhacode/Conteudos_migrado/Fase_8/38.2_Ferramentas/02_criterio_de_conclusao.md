## Critério de conclusão
A pessoa desenha o fluxo de sinais e explica o papel de cada ferramenta, coleta ou simula métricas, escreve consultas corretas para taxa/erro/p95, cria um dashboard interpretável e investiga uma anomalia com evidências sem expor dados sensíveis.
