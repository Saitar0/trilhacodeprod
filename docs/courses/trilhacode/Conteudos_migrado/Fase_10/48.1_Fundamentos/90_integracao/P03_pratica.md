### Atividade 3 — Comparar duas opções com evidências
Use o mesmo conjunto de exemplos da atividade 1 para comparar duas opções permitidas (dois modelos, versões ou provedores). Consulte documentação oficial vigente para capacidade, preço, disponibilidade e condições de dados. Registre versão, data, parâmetros, latência, falhas, resultado por caso e estimativa de custo por tarefa aceitável. Se não houver acesso a duas APIs, use documentação e resultados fornecidos pelo instrutor, identificando claramente os dados simulados.

**Entregável:** tabela de comparação, recomendação para o caso e lista de limitações/itens ainda não medidos.
