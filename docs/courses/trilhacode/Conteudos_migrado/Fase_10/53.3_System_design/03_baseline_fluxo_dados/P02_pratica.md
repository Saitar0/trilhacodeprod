### Atividade 2 — Desenho mínimo e evolução justificada
**Contexto e objetivo:** propor um caminho de leitura e escrita coerente com os requisitos definidos na Atividade 1.

**Instruções:** desenhe cliente, API, armazenamento e geração de identificador; descreva endpoints ou operações de criar e redirecionar URL, dados mínimos e índices. Depois responda a duas mudanças: (a) leitura cresce muito mais que escrita; (b) o serviço de resolução depende de uma API externa lenta. Só acrescente cache, fila, CDN ou isolamento de serviço se justificar requisito, benefício e novo modo de falha.

**Entrega:** diagrama simples, descrição do fluxo de criação/redirecionamento e tabela “mudança → decisão → trade-off”.

**Dica gradual:** siga a requisição e os dados antes de escolher infraestrutura. Para cada componente, complete: “adiciono ___ porque ___; agora preciso tratar ___”.
