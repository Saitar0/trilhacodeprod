### Marco 4 — Revise, registre a cobertura e entregue
**Objetivo:** tornar a entrega reproduzível e registrar cobertura somente com evidência suficiente.

**Tarefas:**
1. Revise escopo, diff, acessibilidade básica, configuração, tratamento de erros e coerência entre documentação e implementação.
2. Para **T4**, compare a lista sem virtualização e com a alternativa, sob dados, viewport, dispositivo, ferramenta e cache descritos; mantenha virtualização só se a medida justificar o custo. Para outros tipos, registre a evidência final da regra central sem criar uma otimização artificial.
3. Atualize README com pré-requisitos, configuração de exemplo, comandos, cenários, resultado, limites e separação entre mock e API real.
4. Confira se a ideia é não repetida para crédito; atualize o guia de cobertura apenas quando todos os critérios da ideia estiverem demonstrados. Registre evidência rastreável. Repetição opcional não altera a cobertura.
5. Prepare uma demonstração breve do caminho central e de uma falha ou recuperação.

**Evidências:** README reproduzível; revisão final; resultado de teste e demonstração; medida comparável do T4, quando aplicável; atualização ou justificativa explícita para não atualizar o registro de cobertura.

**Verificação:** outra pessoa consegue seguir o README, distinguir o que foi simulado e conectado ao servidor e avaliar o requisito específico sem depender de explicação oral.
