## Resumo
- O contrato define formatos, presença, nulidade, erros e parâmetros HTTP.
- Tipos TypeScript não validam automaticamente dados recebidos pela rede.
- Trate JSON como `unknown` até validar e adaptar.
- Diferencie campo ausente de campo `null`.
- Avalie compatibilidade de mudanças com consumidores e testes de contrato.
