## Resumo
- Vite cobre o fluxo de desenvolvimento e a geração do build; ele não mantém estado da interface nem serve automaticamente a aplicação em produção.
- Zustand é uma opção para estado de cliente compartilhado; use seletores e mantenha estado local local quando não houver necessidade de compartilhamento.
- TanStack Query administra consultas e cache de dados remotos; chaves devem refletir todos os parâmetros que mudam o resultado.
- Copiar dados remotos para outra store exige fonte de verdade e política explícitas de sincronização.
- Antes de instalar uma ferramenta, descreva a necessidade e compare com o que o projeto já oferece.
