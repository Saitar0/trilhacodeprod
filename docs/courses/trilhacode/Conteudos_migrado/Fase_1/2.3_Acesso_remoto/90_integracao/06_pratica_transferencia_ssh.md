### 3. Transferência — configure e confirme o acesso SSH

Use um repositório de teste ou um repositório ao qual você já tenha acesso. Siga a documentação oficial para verificar se já possui uma chave adequada; gere um par novo somente se necessário. Proteja a chave privada, cadastre apenas a pública na conta correta e teste a conexão. Antes de confirmar uma chave de host na primeira conexão, compare a impressão digital com a publicada pelo GitHub. Depois, confira a URL remota do repositório e identifique se ela usa SSH ou HTTPS.

Registre um relatório sem segredos com o sistema usado, as etapas concluídas, o tipo de URL remota, o resultado observável do teste SSH e a diferença entre chave pública, privada e token. Não inclua conteúdo de arquivos de chave nem passphrase.
