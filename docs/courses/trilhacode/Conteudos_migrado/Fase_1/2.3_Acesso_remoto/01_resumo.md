## Resumo
- SSH cria um canal seguro para acessar serviços e máquinas remotas.
- A chave pública é cadastrada no destino; a privada permanece secreta e protegida.
- Uma passphrase pode proteger a chave privada; um agente pode mantê-la disponível na sessão.
- GitHub aceita acesso SSH quando a chave pública está cadastrada e o remoto usa URL SSH.
- Token de aplicação e chave SSH são credenciais distintas.
- Confira mudanças inesperadas na chave de host e nunca compartilhe a chave privada.
