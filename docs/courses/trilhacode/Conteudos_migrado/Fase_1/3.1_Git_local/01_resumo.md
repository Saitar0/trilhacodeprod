## Resumo
- `git init` inicia um repositório; `git status` apresenta o estado atual.
- Working tree é onde se edita; staging area seleciona mudanças; commit registra um snapshot.
- Revise `git diff` e `git diff --staged` antes de registrar.
- `git log` e `git show` ajudam a entender o histórico.
- Branches isolam linhas de trabalho sem duplicar o repositório inteiro.
- `git restore` e `git reset` têm efeitos diferentes; `--hard` pode descartar trabalho.
- `.gitignore` evita rastrear certos arquivos novos, mas não apaga arquivos já rastreados.
- Nunca inclua credenciais no histórico; se expostas, revogue-as primeiro.
