### 2. Independente — corrija um setup incompleto

Uma pessoa recebe este trecho de README:

```text
Instale o editor, o Node e o Git.
No terminal, rode os comandos do instalador encontrados na internet.
Se não funcionar, use administrador.
Coloque a chave do serviço em .env e envie o projeto para o GitHub.
```

**Entregue:** uma versão corrigida com pelo menos seis passos numerados. Ela deve nomear o sistema e o shell suportados, indicar fontes oficiais, explicar como verificar as ferramentas, orientar a criação de um arquivo de exemplo sem segredo, dizer como manter o arquivo local com credenciais fora do Git e incluir uma forma de pedir ajuda com contexto suficiente. Você pode declarar uma rota específica, como Windows com PowerShell, macOS com zsh ou Linux com Bash; não precisa cobrir todos os sistemas.

**Dicas progressivas**

- Separe pré-requisitos, instalação, configuração e verificação. “Instale o Node” não informa versão nem como saber se funcionou.
- Um arquivo `.env.example` pode mostrar nomes e valores fictícios. O arquivo `.env` real deve ficar fora do controle de versão; confirme também que não foi incluído por engano antes de publicar.
