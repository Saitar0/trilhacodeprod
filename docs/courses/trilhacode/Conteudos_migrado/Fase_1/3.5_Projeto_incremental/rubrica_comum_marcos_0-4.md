**Rubrica comum para cada marco (0–4):** 4 = evidências completas e verificação aprovada; 3 = entrega aprovada com uma lacuna menor; 2 = artefato existe, mas falta evidência ou uma verificação importante; 1 = entrega incompleta ou difícil de usar; 0 = sem evidência avaliável. Os marcos 3 e 4 não são aceitos enquanto houver credencial real ou dado pessoal versionado.
