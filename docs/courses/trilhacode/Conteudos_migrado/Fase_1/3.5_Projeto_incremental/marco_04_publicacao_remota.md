### Marco 4 — publicação e conferência remota

**Tarefas:** publique o repositório no GitHub sem arquivos sensíveis. Atualize a issue inicial conforme o resultado do trabalho. Revise README, commits, estado da branch e conteúdo remoto; registre no README como navegar pelos exercícios e projetos.

**Evidência:** repositório remoto acessível, issue atualizada, commits publicados e README final.

**Verificação:** clone o remoto em uma pasta limpa, confira se a branch e os arquivos esperados chegaram e siga novamente as instruções do README e do setup. Compare o resultado com o repositório original e corrija divergências.
