## Resumo
- O repositório de estudos será uma base contínua para exercícios e projetos.
- Organize por conteúdo real; mantenha a estrutura simples e evolutiva.
- Escolha gestor de tarefas, loja virtual ou base de conhecimento para o Trilho A e registre a justificativa.
- A escolha pode ser trocada uma vez até o fim da Fase 4, documentando o motivo.
- Versione apenas configurações revisadas e seguras; nunca inclua chaves privadas ou tokens.
- README deve permitir compreender objetivo, requisitos e primeiros passos.
