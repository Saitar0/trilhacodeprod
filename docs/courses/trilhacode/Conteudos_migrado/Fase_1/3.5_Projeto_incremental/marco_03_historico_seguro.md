### Marco 3 — histórico e configuração segura

**Tarefas:** adicione um `.gitignore` adequado ao ambiente; revise e versione somente configurações pessoais que possam ser compartilhadas com segurança, ou explique no README por que não adicionará dotfiles. Faça commits pequenos e claros. Antes de cada commit, inspecione `git status`, `git diff` e `git diff --staged`.

**Evidência:** `.gitignore`, histórico recente, estado limpo após os commits e justificativa sobre dotfiles.

**Verificação:** use apenas um arquivo de teste com valor fictício para conferir se o padrão de ignore funciona; confirme que ele não aparece como rastreado. Revise os arquivos preparados e os já commitados em busca de credenciais e dados pessoais. Se uma credencial real tiver sido commitada, interrompa a entrega, revogue/rotacione-a e siga o processo de resposta antes de prosseguir.
