**Gabarito comentado:** a revisão deve solicitar mudanças, pois o sinal subtrai o imposto. Um comentário útil seria: “Com preço 100 e taxa 0,10, esta expressão retorna 90, mas o requisito espera 110. Pode somar a parcela do imposto e incluir um teste para esse caso?” O comentário identifica o resultado, mostra a evidência e pede uma ação verificável. A decisão de revisão não substitui a configuração de regras do repositório.
