### 3. Transferência — publique e revise uma pull request

Crie um repositório de estudo sem dados sensíveis, clone-o, faça uma branch e altere o README para explicar propósito, requisitos e uso. Envie a branch e abra uma pull request para a branch principal. Peça revisão a alguém; se estiver trabalhando sozinho, faça uma auto-revisão do diff e registre uma observação concreta e a melhoria correspondente. Responda ao feedback recebido com uma alteração ou justificativa e integre a mudança conforme as permissões e regras do repositório.

Antes de enviar, inspecione o diff e confirme que `.env`, tokens, chaves, dados pessoais e arquivos de ambiente não aparecem nele. Na descrição da PR, inclua contexto, mudança realizada e como verificar o resultado. Depois da integração, confira o estado final da branch e do remoto.
