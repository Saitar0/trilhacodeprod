### Organização e fluxo
README explica propósito, uso, requisitos e como contribuir. Issues ajudam a registrar tarefas e decisões; labels e milestones podem organizar o trabalho se forem necessários. GitHub Flow é um fluxo simples comum: criar branch, fazer mudanças, abrir PR, revisar e integrar. GitFlow é outro modelo com branches e convenções próprias; não é requisito universal nem nome genérico para qualquer trabalho com branches.
