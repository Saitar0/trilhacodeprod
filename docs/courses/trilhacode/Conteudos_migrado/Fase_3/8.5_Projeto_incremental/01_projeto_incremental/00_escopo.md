## Escopo do projeto
Este projeto acrescenta uma camada de interface ao problema escolhido na Fase 1. A meta é demonstrar estrutura semântica, interação, organização do código, modelagem TypeScript e publicação de arquivos estáticos — não construir um produto completo.

Uma página estática é composta por arquivos servidos ao navegador. TypeScript precisa ser verificado e transformado em JavaScript pelo build; o navegador normalmente recebe HTML, CSS, JavaScript e arquivos de dados. Um JSON local serve como fonte demonstrativa, mas não oferece persistência compartilhada nem substitui uma API.

A entrega mínima tem uma página com uma listagem e um formulário. O formulário pode atualizar estado apenas em memória ou apresentar uma confirmação demonstrativa. Explique o que acontece com os dados quando a página é recarregada. Hospedagem estática publica os arquivos de saída; ela não executa backend, guarda segredos nem implementa autorização.
