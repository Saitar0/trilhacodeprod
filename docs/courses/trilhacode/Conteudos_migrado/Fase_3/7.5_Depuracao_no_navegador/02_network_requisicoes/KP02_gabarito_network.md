**Solução de referência:** A: resposta recebida; verifique caminho e disponibilidade da rota. B: sem status legível; consulte Console e detalhes para investigar rede ou bloqueio, sem afirmar CORS sem evidência. C: sucesso HTTP com resultado vazio; confirme se o contrato permite esse resultado e como a interface o representa. D: resposta HTTP malsucedida; registre status e corpo seguro e investigue o endpoint. Em cada caso, o próximo passo deve testar uma hipótese.
