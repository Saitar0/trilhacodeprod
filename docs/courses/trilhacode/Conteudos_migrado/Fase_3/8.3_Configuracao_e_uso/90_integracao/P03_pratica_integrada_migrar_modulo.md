### 3. Integrada — migre um módulo e documente o fluxo
Escolha um módulo JavaScript pequeno com um consumidor. Registre uma entrada representativa e a saída esperada. Converta o módulo para TypeScript, tipando contratos públicos; ajuste consumidores; configure checagem/emissão para o ambiente e execute o processo real do projeto. Se outra ferramenta gerar o JavaScript, explique como TypeScript participa da checagem sem duplicar a emissão.

**Entregáveis:** lista de arquivos alterados; opções explicadas; comando de verificação/build; exemplo de comportamento antes/depois; diagnósticos resolvidos e exceções temporárias justificadas.

**Dicas:** escolha um módulo de baixo risco; confirme se entrou no projeto; não passe o caminho do arquivo ao tsc se espera usar tsconfig; mantenha saída fora das fontes; compare o mesmo cenário antes e depois.
