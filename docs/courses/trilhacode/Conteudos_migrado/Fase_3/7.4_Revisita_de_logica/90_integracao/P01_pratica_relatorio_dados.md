## Prática — relatório sobre dados
Receba um JSON de pedidos fictícios com identificador, cliente, itens, total e status. Implemente funções para filtrar pedidos concluídos, transformar cada um em uma linha de relatório e calcular total por cliente. Compare uma implementação com uma passagem e outra com várias passagens. Descreva uma pilha de ações de desfazer e uma fila de pedidos de processamento para o mesmo domínio.
