## Resumo
- `map` transforma, `filter` seleciona, `reduce` acumula.
- Arrays representam sequências; objetos representam propriedades nomeadas.
- O(n) indica trabalho que cresce proporcionalmente à quantidade de itens.
- Várias passagens sequenciais ainda são O(n); loop aninhado pode mudar a ordem de crescimento.
- Pilha é LIFO; fila é FIFO.
- Escolha operações/estrutura conforme uso e custo, não só pelo nome.
