## Resumo
- `let`/`const` têm escopo de bloco; `var` tem regras diferentes e raramente é necessário no código novo.
- Arrow functions podem retornar implicitamente expressões, mas blocos precisam de `return`.
- Template strings interpolam expressões com `${}`.
- Destructuring extrai valores de estruturas.
- Spread expande; rest reúne os elementos restantes.
- Cópia com spread é rasa; dados internos ainda podem ser compartilhados.
- Arrow functions não têm `this` próprio; preserve funções tradicionais onde o método ou construtor depende desse comportamento.
