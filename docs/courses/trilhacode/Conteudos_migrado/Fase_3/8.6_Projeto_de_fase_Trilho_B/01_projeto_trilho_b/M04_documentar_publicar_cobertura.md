### Marco 4 — documentar, publicar e registrar cobertura
Execute o build e confira que a saída estática contém os arquivos necessários. Publique em um provedor compatível, abra o endereço publicado e repita os cenários centrais no site implantado. Atualize o README com objetivo, tipo, instruções, build, URL e limites. Só marque cobertura do tipo no guia se o critério correspondente tiver sido demonstrado; repetição de tipo concluído não cria nova cobertura.

**Evidências:** comando e resultado do build; endereço público; cenários repetidos após publicação; README atualizado; tabela de cobertura alterada somente quando elegível.
