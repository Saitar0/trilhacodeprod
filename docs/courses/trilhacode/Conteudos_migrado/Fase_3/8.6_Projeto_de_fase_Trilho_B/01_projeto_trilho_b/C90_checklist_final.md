- [ ] Defini e implementei somente a fatia mínima do tipo.

- [ ] Organizei o TypeScript em módulos e registrei a checagem/build.
- [ ] Usei HTML semântico, CSS responsivo e interações acessíveis por teclado.
- [ ] Executei os cenários mínimos do tipo e registrei esperado versus observado.
- [ ] Documentei a simulação e os limites no README.
- [ ] Publiquei e conferi a versão pública.
- [ ] Atualizei a tabela de cobertura apenas quando o tipo pendente foi demonstrado.
