### Marco 2 — cenário, dados e interface mínima
Defina um cenário principal reproduzível e os dados locais necessários. Crie JSON coerente com o tipo escolhido e um esboço da interface. Inclua estados de carregamento, sucesso, vazio ou erro quando forem aplicáveis. Use elementos HTML adequados, rótulos claros e operações possíveis por teclado.

**Evidências:** amostra de dados; fluxo em passos; esboço da interface; lista dos estados que a pessoa verá e como chegar a cada um.

**Checagem comum:** outra pessoa consegue seguir o cenário sem receber instruções verbais adicionais? A interface continua compreensível sem mouse?
