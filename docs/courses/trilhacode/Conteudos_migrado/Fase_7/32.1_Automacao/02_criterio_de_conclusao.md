## Critério de conclusão
O workflow executa lint, build e testes de CI de forma reproduzível nos pull requests. O check correto é exigido pela proteção de branch (ou a limitação de acesso é registrada sem alegar bloqueio não verificado), uma falha deliberada é detectada e restaurada, e a revisão documenta eventos, permissões, secrets e dependências de Actions.
