### Texto alternativo de imagens
O atributo `alt` deve comunicar a informação relevante da imagem naquele contexto. Se a imagem for decorativa e não acrescentar informação, use `alt=""` para que tecnologias assistivas não anunciem ruído. Se uma imagem funcionar como link, descreva a finalidade do link. Evite descrições repetitivas como “imagem de” quando o contexto já informa que é uma imagem.
