**Solução comentada:** associe um `<label for="email">E-mail</label>` a um campo com `id="email"`; dê à imagem do link um texto que expresse sua finalidade, como `alt="Consultar como chegar ao encontro"`; use `alt=""` no separador se ele for puramente decorativo; remova a regra que apaga o foco ou substitua-a por um indicador visível para teclado. Verifique cada alteração por inspeção do HTML e navegação por teclado. O botão nativo já é focável; o problema nesse trecho é não conseguir perceber o foco, não a ausência de foco.

**Erros comuns:** tratar placeholder como substituto permanente de label; descrever a aparência da imagem quando ela funciona como link; deixar texto alternativo em decoração sem função; concluir que o botão não recebe foco só porque o indicador foi removido.
