## Verificação — quiz
1. Qual elemento identifica o conteúdo principal da página? **A)** `main`. **B)** `aside`. **C)** `footer`. **D)** `span`.
2. Quando `article` é uma escolha plausível? **A)** Para qualquer caixa visual. **B)** Para conteúdo independente que pode fazer sentido fora do contexto imediato, como uma publicação. **C)** Para estilizar texto em negrito. **D)** Para substituir CSS.
3. Qual diferença melhor descreve `section` e `div`? **A)** `section` agrupa tema semanticamente; `div` é contêiner genérico. **B)** São idênticos em semântica. **C)** `div` sempre cria navegação. **D)** `section` é apenas para imagens.
5. Avalie as afirmações: **I.** Um grupo deve virar `<section>` sempre que precisar de uma borda visual. **II.** Um `<header>` ou `<footer>` pode introduzir ou encerrar a página inteira ou um conteúdo como um `<article>`. **A)** Apenas I. **B)** Apenas II. **C)** I e II. **D)** Nenhuma.
