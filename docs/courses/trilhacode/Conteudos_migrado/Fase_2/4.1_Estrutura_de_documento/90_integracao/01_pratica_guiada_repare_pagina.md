## Prática — três níveis

Faça as atividades nesta ordem. Use somente informações fictícias; não publique dados pessoais. A atividade final é uma página completa e deve ser validada.

### 1. Guiada — repare uma página incompleta

O arquivo abaixo representa uma página de guia de estudos. Identifique pelo menos seis melhorias relacionadas a idioma e metadados, fechamento/aninhamento, link, imagem, tabela e formulário. Reescreva o trecho para que atenda ao briefing: idioma português do Brasil; título da aba “Guia de estudos”; lista de três tópicos; link para o perfil do grupo com texto descritivo; imagem informativa com alternativa textual; tabela com cabeçalhos de fase e status; campo de e-mail associado a um rótulo. O formulário é demonstrativo e não deve enviar dados.

```html
<!doctype html>
<html>
<head>
  <title>Guia de estudos</title>
<body>
  <h1>Guia de estudos
  <p>Materiais para a próxima etapa
  <ul><li>HTML<li>CSS<li>JavaScript</ul>
  <a href="https://example.com">Clique aqui</a>
  <img src="mapa.png">
  <table>
    <tr><td>Fase</td><td>Status</td></tr>
    <tr><td>HTML</td><td>Em andamento</td></tr>
  </table>
  <form>
    <input id="email" type="email" placeholder="E-mail">
    <button>Enviar</button>
  </form>
</body>
</html>
```
