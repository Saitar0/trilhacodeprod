**Resposta: A.** Grid define faixas nas duas dimensões; as outras opções não descrevem uma necessidade de estrutura bidimensional.
**Resposta: C.** O tamanho mínimo automático de uma faixa/item pode resistir ao encolhimento. A correção depende de identificar a caixa e também do comportamento desejado para o conteúdo; posicionamento absoluto ou troca automática de tecnologia não explicam a causa.
