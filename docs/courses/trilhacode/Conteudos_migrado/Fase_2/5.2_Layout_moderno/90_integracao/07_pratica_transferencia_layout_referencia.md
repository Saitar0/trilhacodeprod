### 3. Transferência — reproduza e revise um layout de referência
Escolha uma página simples com cabeçalho, navegação, área principal e cartões. Construa a estrutura com o HTML existente e reproduza a composição usando Grid para relações bidimensionais e Flexbox para grupos unidimensionais. Registre por que cada contêiner usa aquele modo e como os itens se comportam quando falta espaço.

**Entregue:** referência identificada, mapa de contêineres, CSS relevante, comparação visual em largura ampla e estreita e uma nota sobre qualquer diferença que você decidiu manter.
