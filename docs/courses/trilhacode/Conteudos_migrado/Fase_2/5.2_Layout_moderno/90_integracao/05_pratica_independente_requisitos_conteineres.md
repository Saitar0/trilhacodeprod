### 2. Independente — mapeie requisitos para contêineres
Projete, para a página já criada no curso, uma área principal com título, uma barra de ações e uma coleção de quatro cartões. Antes de escrever o CSS, faça um mapa `Região | Relação entre itens | Modelo escolhido | Evidência/razão`.

Implemente pelo menos um contêiner com Flexbox e um com Grid. Defina o que deve acontecer quando a barra não couber em uma linha e quando os cartões perderem espaço. Registre quais propriedades controlam alinhamento no eixo principal e transversal da barra. Não é necessário copiar uma referência visual nesta etapa.

**Dicas graduais:** (1) pergunte se a relação dominante é uma sequência ou linhas e colunas; (2) desenhe os dois eixos antes de escolher propriedades de alinhamento; (3) teste com texto de comprimentos diferentes e janela estreita.
