## Resumo
- SELECT escolhe colunas e expressões; FROM identifica a fonte.
- WHERE filtra apenas linhas cuja condição resulta em verdadeiro.
- NULL exige IS NULL/IS NOT NULL, e lógica SQL pode resultar em desconhecido.
- ORDER BY define a ordem; use desempate único para resultados previsíveis com LIMIT.
- Parâmetros do driver protegem valores fornecidos pelo usuário; não concatene entrada em SQL.
