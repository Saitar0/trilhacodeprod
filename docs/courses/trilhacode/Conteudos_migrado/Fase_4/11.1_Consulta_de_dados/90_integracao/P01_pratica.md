## Práticas

### Atividade 1 — Projete e filtre resultados
Considere Pedido(`id), `cliente_id), `status), `total), `criado_em), `observacao). Escreva uma consulta para listar id, status, total como valor_pedido e criado_em somente para pedidos pagos com total a partir de 100.

**Tarefas**
1. Escolha explicitamente as colunas.
2. Aplique os dois filtros exigidos.
3. Explique por que observar todos os campos com SELECT * não é necessário.

**Dica:** uma condição simples por regra torna a consulta fácil de conferir.
