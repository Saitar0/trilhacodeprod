## Resumo
- Conexão depende de host, porta, banco, usuário e autorização.
- psql mistura instruções SQL com metacomandos próprios iniciados por barra invertida.
- Scripts versionados recriam estrutura e dados didáticos; CREATE DATABASE é feito a partir de outro banco.
- Confira o alvo de UPDATE/DELETE antes de executar e use RETURNING para observar as linhas afetadas.
- BEGIN, COMMIT e ROLLBACK controlam a confirmação de um conjunto de alterações.
