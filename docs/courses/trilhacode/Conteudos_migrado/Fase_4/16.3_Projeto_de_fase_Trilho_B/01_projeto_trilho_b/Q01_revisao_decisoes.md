## Revisão das decisões
- Qualquer pessoa consegue dizer qual tipo foi escolhido, qual regra o distingue e como a evidência prova essa regra?
- O índice foi proposto a partir da consulta e do plano, ou apenas adicionado por expectativa?
- Os dados de exemplo são suficientes para a pergunta e permitem conferir o relatório?
- As conclusões de desempenho estão limitadas às condições realmente medidas?
- O tipo só foi marcado na cobertura depois do aceite correspondente?
