## Checklist final
- [ ] O projeto é a continuação do Trilho A escolhido em 3.5.
- [ ] README, diagrama e fatia estão coerentes.
- [ ] Compose inicia PostgreSQL, Redis e MongoDB com configuração local segura e persistência explicada.
- [ ] PostgreSQL tem migrations reproduzíveis, constraints e dados de demonstração.
- [ ] Consulta real e caso inválido têm teste ou roteiro reproduzível.
- [ ] Redis tem justificativa, chave completa, TTL, miss/hit e invalidação pós-escrita demonstrados.
- [ ] Medição antes/depois usa condições anotadas e conclusão proporcional à evidência.
- [ ] MongoDB tem caso documental delimitado, documento e consulta de exemplo.
- [ ] Autoridade, duplicação e sincronização dos dados estão explicadas.
- [ ] README descreve como iniciar, verificar e limpar o ambiente sem apagar dados por acidente.
