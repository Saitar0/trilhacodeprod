## Critério de conclusão
Uma pessoa consegue reproduzir a fatia do projeto a partir do README; PostgreSQL protege as regras relacionais; o uso ou a rejeição de Redis é sustentado por evidências; MongoDB tem um papel documental delimitado; e as quatro entregas têm artefatos verificáveis.
