## Resumo
- Tabela agrupa ocorrências; coluna descreve atributo; linha representa uma ocorrência.
- Esquema define estrutura, tipos e restrições; ordem das linhas não é garantida sem ordenação.
- PK identifica uma linha de forma única e não nula; pode ser simples ou composta.
- FK declara uma referência e ajuda a manter integridade entre tabelas.
- 1:N normalmente coloca a FK no lado N; N:N usa uma tabela associativa.
- JSON é formato de dados e pode coexistir com um banco relacional.
