# Referências — Fase 1 (piloto do padrão)

> [!abstract] Como usar
> Lista de referências selecionadas para a Fase 1. Cada item segue o padrão
> do [[Guia_de_Producao_de_Conteudo|guia de produção]]: **título + URL + o que cobre**.
> Antes de produzir cada unidade, confira a URL e a cobertura da referência e
> registre a data da conferência no conteúdo. Materiais secundários são
> complementares, não substitutos das fontes principais.

## 1.1 — Computação e software

- **MDN — How the web works** · https://developer.mozilla.org/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works · cliente, servidor, requisição/resposta, DNS e HTTP no navegador.
- **HTTP Overview (MDN)** · https://developer.mozilla.org/docs/Web/HTTP/Overview · noção de HTTP, mensagens, métodos e status.

## 1.2 — Ambiente de desenvolvimento

- **WSL Documentation (Microsoft Learn)** · https://learn.microsoft.com/windows/wsl/ · instalação e uso do WSL no Windows.
- **Microsoft Learn — Environment variables (Win32)** · https://learn.microsoft.com/en-us/windows/win32/procthread/environment-variables · bloco de ambiente de processos e herança de variáveis para processos filhos.

## 2.1 — Terminal e navegação

- **GNU Coreutils Manual** · https://www.gnu.org/software/coreutils/manual/ · referência de `ls`, `cp`, `mv`, `rm`, `find` e redirecionamento.
- **The Unix Shell (Software Carpentry)** · https://swcarpentry.github.io/shell-novice/ · tutorial de navegação, pipes e redirecionamento.

## 2.2 — Sistema e operação

- **Linux man pages — chmod/chown** · https://man7.org/linux/man-pages/man1/chmod.1.html · permissões e donos de arquivo.
- **Linux man pages — grep** · https://man7.org/linux/man-pages/man1/grep.1.html · busca em texto e logs.

## 2.3 — Acesso remoto

- **OpenSSH Manual** · https://www.openssh.com/manual.html · SSH, chaves e conexão remota.
- **GitHub — Connecting to GitHub with SSH** · https://docs.github.com/authentication/connecting-to-github-with-ssh · gerar par de chaves e autenticar no GitHub.

## 3.1 — Git local

- **Pro Git (Scott Chacon, gratuito)** · https://git-scm.com/book/ · referência completa de init, add, commit, log, diff, reset e branch.
- **Git Reference (git-scm)** · https://git-scm.com/docs · documentação oficial de comandos.

## 3.2 — Trabalho com histórico

- **Pro Git — Branching e Merging** · https://git-scm.com/book/en/v2/Git-Branching-Basic-Branching-and-Merging · merge, rebase e resolução de conflitos.
- **Git — Conventional Commits** · https://www.conventionalcommits.org/ · boas mensagens de commit.

## 3.3 — GitHub

- **GitHub Docs — Pull requests** · https://docs.github.com/pull-requests · fluxo de pull request e code review.
- **GitHub Docs — Git Flow (visão geral de fluxos)** · https://docs.github.com/get-started/using-git/about-git · organização de repositórios e fluxos de branch.

## 3.4/3.5 — Revisita contínua e projeto da fase

- **GitHub Docs — About READMEs** · https://docs.github.com/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes · organização do README.
- **Dotfiles (Awesome Dotfiles)** · https://github.com/webpro/awesome-dotfiles · exemplos de setup versionado.
