# Referências — Fase 2

> [!abstract] Como usar
> Lista de referências selecionadas para a Fase 2. Cada item segue o padrão
> do [[Guia_de_Producao_de_Conteudo|guia de produção]]: **título + URL + o que cobre**.
> Antes de produzir cada unidade, confira a URL e a cobertura e registre a data da conferência no conteúdo; materiais secundários complementam, mas não substituem as fontes principais.
> Mínimo de 2 referências por submódulo obrigatório e 1 por repertório/opcional.

## 4.1 — Estrutura de documento

- **MDN — Introduction to HTML** · https://developer.mozilla.org/docs/Learn_web_development/Core/Structuring_content · estrutura básica, head/body, títulos, parágrafos, listas e links.
- **MDN — HTML elements reference** · https://developer.mozilla.org/docs/Web/HTML/Element · referência de imagens, tabelas e formulários.

## 4.2 — HTML semântico

- **MDN — HTML text fundamentals e semantic elements** · https://developer.mozilla.org/docs/Learn_web_development/Core/Structuring_content · header, nav, main, section, article, aside e footer.
- **W3C — HTML: sections (spec)** · https://html.spec.whatwg.org/multipage/sections.html · definição formal dos elementos de seção.

## 4.3 — Acessibilidade inicial

- **W3C WAI — Accessibility Fundamentals** · https://www.w3.org/WAI/fundamentals/ · princípios de acessibilidade e navegação por teclado.
- **MDN — Accessibility** · https://developer.mozilla.org/docs/Learn_web_development/Core/Accessibility · labels, alt, hierarquia e estrutura acessível.

## 5.1 — Base visual

- **MDN — CSS first steps** · https://developer.mozilla.org/docs/Learn_web_development/Core/Styling_basics · seletores, cascata e especificidade.
- **MDN — The box model** · https://developer.mozilla.org/docs/Learn_web_development/Core/Styling_basics/Box_model · box model, display, position e espaçamento.

## 5.2 — Layout moderno

- **MDN — Flexbox** · https://developer.mozilla.org/docs/Learn_web_development/Core/CSS_layout/Flexbox · alinhamento e distribuição em uma dimensão.
- **MDN — CSS Grid Layout** · https://developer.mozilla.org/docs/Web/CSS/CSS_grid_layout · grid e composição de layouts.

## 5.3 — Responsividade

- **MDN — Responsive design** · https://developer.mozilla.org/docs/Learn_web_development/Core/CSS_layout/Responsive_Design · medidas relativas, media queries e mobile first.
- **MDN — CSS media queries** · https://developer.mozilla.org/docs/Web/CSS/CSS_media_queries/Using_media_queries · uso prático de media queries.

## 5.4 — Organização visual

- **MDN — Organizing your CSS** · https://developer.mozilla.org/docs/Learn_web_development/Core/Styling_basics/Organizing · estruturação e manutenção de estilos.
- **Tailwind CSS — Core concepts** · https://tailwindcss.com/docs/utility-first · abordagem utility-first (repertório).
