# Instruções para agentes

- Leia este arquivo e as instruções aplicáveis mais próximas antes de editar.
- Preserve alterações locais preexistentes. Antes de mudar de branch, commit ou fazer limpeza, identifique o estado do working tree e não inclua arquivos fora do escopo.
- Use `main` como base de branches e Pull Requests; confirme o estado remoto quando o clone local estiver atrasado.
- Mantenha as mudanças pequenas, compatíveis com a arquitetura atual e sem funcionalidades de IA no produto, salvo autorização explícita.
- Execute os testes existentes relevantes quando houver mudança de código e informe os comandos e resultados. Não considere relatórios antigos como validação da revisão atual.
- Não faça merge em `main`, deploy, migração, seed ou operações contra banco compartilhado/real sem autorização específica.
- Consulte `docs/ai-team/` para o escopo e o registro da missão vigente.
